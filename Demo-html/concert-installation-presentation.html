Product Suite Overview

IBM Concert / Installation Guide / 2025 / © 2025 IBM Corporation 03

The IBM Concert Platform

IBM Concert
The core AIOps platform. Provides unified observability, risk scoring, and change management for complex multi-cloud environments. Accessed on port 12443.
Concert Workflows
Automation and orchestration engine. Connects hundreds of integrations, automates remediation workflows, and reduces mean time to resolution. Accessed on port 443.
Concert Data Apps
Low-code platform for building full-featured, data-driven applications. Connect SQL, REST, GraphQL sources and build rich dashboards beyond static visualization. Port 15443.
Note: For new installations on x86 VMs, K3s (a lightweight distribution of Kubernetes) is automatically installed. Its native containerd runtime is used as the default container runtime for all product components.

Prerequisites — Root User Installation

  • System meets all VM sizing specifications
  • Valid IBM Entitlement Key obtained from myibm.ibm.com
  • Log in as root user or use sudo for all commands
  • Internet access to IBM Container Registry (cp.icr.io)
  • Reviewed and agreed to applicable IBM Software License
  • Optional: External PostgreSQL / MySQL databases pre-configured
Obtaining Your IBM Entitlement Key
1
Log in to IBM Container Library
Navigate to myibm.ibm.com/products-services/containerlibrary
2
Go to Entitlement Keys tab
Click Copy to copy the entitlement key to clipboard
3
Save securely
Store the API key in a text file or secure credential vault before proceeding

Step 1 (Optional) & Step 2 — Configure & Download

Step 1: Configure External Databases (Optional)

You may use external databases instead of the default internal storage. Configure external services for Concert and Concert Data Apps before installation if needed.

Tip: Skip Step 1 for a default installation. Internal databases are provided and configured automatically.
Step 2: Download & Extract Package
# Download from GitHub Releases wget https://github.com/IBM/Concert/releases/\ download/v3.0.0/ibm-concert-x86.tar.gz # Set secure file permissions umask 0022 # Extract the installation package tar -xzf ibm-concert-x86.tar.gz # Export install directory export INSTALL_DIR=<install_dir>/ibm-concert # Navigate to install directory cd $INSTALL_DIR
IBM Concert / Installation Guide / 2025 / © 2025 IBM Corporation 10

Step 3 — Install & Configure Prerequisites

Run the prerequisite management script to install and configure K3s (lightweight Kubernetes) and Helm binaries required for the deployment.

$INSTALL_DIR/bin/manage-prereqs-vm --install # Apply changes to the current session source ~/.bashrc # Verify configuration echo $KUBECONFIG umask # Expected: 0022
What gets installed
K3s
Lightweight Kubernetes
Single-binary K3s distribution with native containerd runtime. Automatically configured as the cluster backend.
Helm
Helm v3.x
Package manager for Kubernetes. Used to deploy Concert component charts into the K3s cluster.
Note: K3s binaries are saved to ibm-concert/prereqs/ directory automatically.
IBM Concert / Installation Guide / 2025 / © 2025 IBM Corporation 11

Step 4 (Optional) — Create Custom Values File

Customize your Concert Workflows installation by creating a custom values file. This allows you to enable advanced features and optimize CPU/memory resource allocation for Workflows microservices.

# Create a custom values file vi $INSTALL_DIR/custom-values.yaml # Example: Optimize resource allocation resources: limits: cpu: "2" memory: "4Gi" # Save and exit (:wq)
Step 5 (Optional): Configure Workflow Integrations

By default, several hundred integrations are installed with Concert Workflows. To speed up installation, configure a custom subset:

  • Install only commonly-used integrations
  • Define a customized integration set
  • Reduces installation time significantly
Note: Applies only if Concert Workflows is included in your installation. See Configuring workflow integrations for details.
IBM Concert / Installation Guide / 2025 / © 2025 IBM Corporation 12

Step 6 — Configure the params.ini File

The params.ini file defines environment-specific settings that the installation script uses to configure all Concert components.

# Copy the appropriate sample params file cp $INSTALL_DIR/etc/sample-params/\ concert-workflows-dataapps-vm-params.ini \ $INSTALL_DIR/etc/params.ini # Open and edit the params file vi $INSTALL_DIR/etc/params.ini
Location: $INSTALL_DIR/etc/params.ini
Key Parameters
ParameterDescription
INSTALL_VMSet to true for VM deployment
INSTALL_CONCERTSet TRUE to install Concert core
INSTALL_WORKFLOWSSet TRUE for Concert Workflows
INSTALL_DATAAPPSSet TRUE for Concert Data Apps
WORKFLOWS_NSFixed namespace: rna-core (do not change)
IBM Concert / Installation Guide / 2025 / © 2025 IBM Corporation 13

Step 7 (Optional) — Authenticate to an LLM Instance

If using AI-powered features in Concert Workflows, configure authentication to your LLM provider before running the installation setup script.

watsonx.ai (SaaS)
export WATSONX_API_KEY=<my-watsonx-api-key>
watsonx.ai (On-Premises)
export WATSONX_API_PASSWORD=<my-secret-password>
vLLM Instance
export LLM_API_KEY=<my-vllm-api-key>
Supported LLM Providers
watsonx.ai
IBM's AI engine for smart predictions, automated text analysis, and workflow automation. Available as SaaS or on-premises deployment.
vLLM Instance
Custom vLLM-provided model instance requiring API key authentication for the vLLM endpoint.
Optional: This step is only required if you plan to use AI-assisted features. You can configure LLM access after installation.
IBM Concert / Installation Guide / 2025 / © 2025 IBM Corporation 14

Step 8 — Run the Installation Setup Script

Set the IBM Container Registry password, then run the setup script to deploy all three products on your VM.

# Set your IBM entitlement key as registry password export REG_PASS=<IBM entitlement key> # Run the installation setup script $INSTALL_DIR/bin/setup \ --license_acceptance=y \ --username=<user> \ --password=<password> \ --registry_password=<registry_entitlement_key>
Important: The --username and --password you specify will become the default login credentials for all installed Concert products.
Setup Script Parameters
ParameterDescription
--license_acceptanceMust be set to y to proceed
--usernameDefault login username for Concert UI
--passwordDefault login password (prompted if omitted)
--registry_passwordIBM Entitlement Key for cp.icr.io
Installation Duration
The installation process takes 15–30 minutes depending on system resources and network speed.

Concert Workflows — Standalone VM Installation

Concert Workflows can also be installed standalone (without Concert core or Data Apps). The root user installation process mirrors the unified install but uses Workflows-specific sample params.

Workflows-Only params.ini
# Copy the Workflows-specific params cp $INSTALL_DIR/etc/sample-params/\ workflows-quickstart-vm-params.ini \ $INSTALL_DIR/etc/params.ini vi $INSTALL_DIR/etc/params.ini
Note: The WORKFLOWS_NS specifies the namespace where Concert Workflows will be installed. The value is fixed as rna-core — do not modify.

Concert Data Apps — Overview & Enablement

Enabling Concert Data Apps

In your params.ini, set the following parameter to enable Data Apps as part of the deployment:

# In params.ini — enable Data Apps INSTALL_DATAAPPS=true # Setting false (or blank) skips Data Apps INSTALL_DATAAPPS=false
Getting Started Workflow
  • Set up a project in the Data Apps section of Concert UI
  • Connect to required data sources (SQL, REST, GraphQL)
  • Create dashboards with tables, charts, forms, KPIs
  • Export Data Apps to run in another instance or environment
Supported Data Sources
SQL Databases

REST APIs
Connect to any REST endpoint for real-time dynamic data
GraphQL
Flexible query layer for aggregating data from multiple services
watsonx.ai
